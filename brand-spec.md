# The Bliss Decor & Events — Brand Spec

- **Visual language:** Dark plum wedding editorial with warm gold accents and soft floral imagery.
- **Primary palette:** `#16080d` ink/plum, `#2a1019` wine, `#e7b82e` gold, `#f7eee9` ivory.
- **Typography:** Cormorant Garamond for display serif; Allura for the welcome script; Manrope for UI/body.
- **Spacing:** 8px base unit, generous 80–130px section rhythm.
- **Buttons:** Pill-shaped, gold primary CTA; translucent outlined secondary/social CTA.
- **Hero asset:** Unsplash wedding floral image used as a subdued atmospheric background, with layered plum overlays for contrast.
- **Instagram:** All profile links point to `https://www.instagram.com/the_bliss_decor_events/`.
